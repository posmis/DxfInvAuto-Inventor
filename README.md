# InvAuto — инструменты автоматизации для Autodesk Inventor

Плагин для Inventor, построенный как расширяемая платформа: каждая функция — отдельный класс,
который автоматически получает свою кнопку на панели **InvAuto** вкладки **«Среды»**.

## Что уже умеет

**Листовые детали** (вкладка «Среды» → панель InvAuto), работает в сборке и в листовой детали.

Окно в стиле Inventor: сверху лента со вкладками, слева дерево состава, в центре список деталей, справа свойства.

- **Лента со вкладками** (открытая вкладка запоминается):
  - «Главная» — Состав (обновить), Список (добавить, добавить все, удалить, очистить), Отметка, Выгрузка DXF;
  - «Развертки» — просмотр, формирование разверток (и заново для выделенных), линии гиба;
  - «Вид» — колонки, сортировка, панель свойств, развернуть/свернуть дерево;
  - «Настройки» — параметры выгрузки, настройки приложения.
- **Поиск** — в заголовке списка деталей (фильтрует список): Ctrl+F — перейти к поиску, Esc — очистить.

- **Дерево состава изделия**: все компоненты с подсборками на любую глубину, колонки
  Обозначение / Наименование / Кол. (в родителе) / Всего (в изделии). Порядок как в спецификации:
  сборки, листовые детали, детали, прочие изделия (стандартные из Библиотеки компонентов и покупные);
  внутри группы — по обозначению. Подавленные, справочные (Reference) и виртуальные компоненты не учитываются.
- **Список деталей собирает пользователь**: выбор в дереве список не меняет. Добавить в список:
  - двойной щелчок по узлу дерева, Enter или Insert, кнопка «Добавить» или контекстное меню дерева.
    Для сборки добавляются все её листовые детали, включая вложенные подсборки; можно выделить
    несколько узлов (Ctrl/Shift + щелчок);
  - «Добавить все» (Ctrl+Shift+A) — все листовые детали изделия.

  Деталь, уже стоящая в списке, повторно не добавляется. Убрать из списка: Delete, «Удалить» или «Очистить»
  (с подтверждением). Файлы при этом не затрагиваются. Количество в списке всегда на всё изделие.
  При «Обновить» список сохраняется, из него убираются только детали, которых больше нет в изделии.
  **Запоминание списка** (Настройки приложения → Общие, по умолчанию выключено): список сохраняется для каждой
  сборки при закрытии окна и восстанавливается при следующем открытии (отметки галочками не запоминаются).
  Хранятся последние 100 сборок; удалить сохранённые списки — «Сброс настроек».
- **Сортировка как в проводнике**: щелчок по заголовку колонки — по возрастанию, повторный — по убыванию,
  стрелка в заголовке показывает направление. Также есть меню «Вид → Сортировка», где можно выбрать и скрытые
  колонки (например, наименование), направление или «Без сортировки» (порядок добавления).
  Числа внутри текста сравниваются по величине («Деталь 2» раньше «Деталь 10»), пустые значения всегда в конце.
  Габариты сортируются по большей стороне. Выбранная сортировка запоминается.
- **Развертки перед выгрузкой**: кнопка «Сформировать развертки» создаёт DXF отмеченных деталей тем же
  способом, что и выгрузка (тот же ini), и показывает их в списке и в панели свойств
  (контур — тёмным, линии гиба — синим пунктиром). При открытии окна DXF не создаются — подгружаются
  только миниатюры и уже сформированные развертки.
- **Кэш разверток**: `%LOCALAPPDATA%\InvAuto\FlatCache`. Имя файла — хэш от пути детали, даты её
  сохранения и настроек выгрузки: изменённая деталь или другой ini дают новую развертку, старые
  удаляются автоматически (по умолчанию через 30 дней, срок — в «Настройках InvAuto»). Выгруженные DXF тоже попадают в кэш. Для несохранённой детали кэш не используется.
- **Просмотр развертки** (кнопка «Просмотр», двойной щелчок по строке или по развертке в панели свойств):
  масштаб колесом мыши вокруг курсора, перемещение левой или средней кнопкой, двойной щелчок или Home — вписать,
  координаты курсора в мм, номера линий гиба. Показывается так, как будет выгружено (с обработанными линиями гиба).
  PageUp/PageDown листают детали списка; несформированная развертка формируется автоматически.
- **Измерения в просмотре развертки**:
  - «Расстояние» (D) — между двумя точками: длина, ΔX и ΔY;
  - «Угол» (A) — между двумя отрезками, вершина в точке пересечения их продолжений. Угол строится
    между теми частями отрезков, по которым щёлкнули, поэтому можно измерить и сам угол, и смежный.
    Для параллельных отрезков выводится расстояние между ними.
  - Привязки берутся из точной геометрии DXF, дуги не разбиваются на участки: конец (квадрат), середина
    (треугольник), центр дуги или отверстия (круг), точка на линии (песочные часы). Ctrl — без привязки.
  - Измерения подписываются на развертке и собираются в список справа, откуда их можно скопировать или удалить.
    При переходе к другой детали измерения сбрасываются.
  - Esc отменяет начатое измерение, второй Esc выключает инструмент. Перемещение вида работает и во время измерения.
- **Клавиши**: в дереве Enter / Insert / двойной щелчок — добавить в список; Ctrl+Shift+A — добавить все;
  в списке Delete — убрать, пробел — отметить, двойной щелчок — просмотр развертки; в просмотре D — расстояние,
  A — угол, Esc — отмена, PageUp/PageDown — соседняя деталь, Home — вписать.
- **Оформление**: все кнопки окон в одном плоском стиле (кнопка по умолчанию — синяя, необратимые действия —
  красным текстом), у колонки сортировки — стрелка направления и выделенный заголовок. Детали, уже добавленные
  в список, отмечены в дереве галочкой (у сборки — если в списке все её листовые детали). На узком экране
  лента прокручивается, а не обрезается.
- **Библиотека материалов** (вкладка «Производство»):
  - материалы листа: наименование (марка, стандарт), толщина, плотность; при первом запуске — сталь 7850 кг/м³
    для толщин 0,5; 1,0; 1,5; 2,0; 3,0; 5,0 мм (наименования можно поменять);
  - «по умолчанию» — материал для своей толщины: его получают все детали этой толщины без ручного назначения;
    по умолчанию для толщины может быть только один материал;
  - «Назначить материал» — вручную для выделенных деталей (по умолчанию показаны материалы той же толщины),
    «По толщине» — снять ручное назначение; удалённый из библиотеки материал → деталь снова по толщине;
  - экспорт в CSV (открывается в Excel) или XML, импорт из них же: новые материалы добавляются, у совпадающих
    по наименованию и толщине обновляется плотность, ничего не удаляется;
  - файл `%APPDATA%\InvAuto\library\materials.xml` — отдельно от настроек и кэша, автоматически не очищается
    («Сброс настроек» и очистка кэша его не трогают); при каждом сохранении прежняя версия копируется в
    `library\backup` (последние 50 копий); повреждённый файл не перезаписывается.
- **Показатели развертки** (после «Сформировать развертки»; колонки и панель свойств):
  материал из библиотеки, площадь без отверстий, масса (площадь × толщина детали × плотность), масса на изделия,
  длина реза (наружный контур и отверстия), число врезок (по замкнутым контурам; незамкнутые подсвечиваются
  в свойствах как признак ошибки в развертке).
- **Проверка перед выгрузкой** («Главная → Выгрузка DXF → Проверить» и автоматически перед выгрузкой):
  - ошибки: нет развертки (если её не создаст выгрузка), развертку не удалось сформировать, контур не замкнут;
  - внимание: модель требует перестроения, деталь не сохранена, нет обозначения, нет материала в библиотеке или
    его толщина не совпадает, отверстия меньше допустимого (толщина × k, но не меньше N мм), отверстия ближе
    к линии гиба, чем толщина × k (в том числе на самой линии), развертка не помещается на лист, одинаковое
    обозначение у разных деталей;
  - результат — в колонке «Проверка» (значок и первое замечание, все — в подсказке), в группе «Проверка»
    таблицы свойств и на развертке в окне просмотра (кружки на местах отверстий и разрывов контура);
  - «Проверить» формирует недостающие развертки и показывает список замечаний; из него можно перейти
    к детали или открыть её развертку;
  - перед выгрузкой при ошибках или предупреждениях показывается список с кнопкой «Выгрузить всё равно»;
  - параметры — «Настройки приложения → Проверка»: коэффициенты и минимумы, размер листа (3000 × 1500),
    обозначение, проверка перед выгрузкой вкл/выкл.
- **Ведомость** («Производство → Ведомость»): отчёт для заявки на резку — в Excel и/или PDF.
  - Шапка: название (по умолчанию «Ведомость листовых деталей», можно задать своё), изделие, дата.
  - Сводка по материалам и толщинам: позиций, деталей, площадь, масса, длина реза, врезки, итог.
  - Таблица деталей по группам материал + толщина: картинка развертки, обозначение, наименование, габариты,
    количество на изделия, площадь и масса одной детали, масса, рез и врезки на все изделия; в конце — замечания
    (нет развертки, нет материала, незамкнутый контур). Нет данных — прочерк, а не ноль.
  - Детали: отмеченные галочкой или весь список. Несформированные развертки формируются перед отчётом.
  - **PDF**: листы A4 альбомные, на каждом — название, изделие и дата сверху, «Лист N из M» снизу; таблица
    переносится на следующий лист с повтором заголовка; шрифт (Arial) встраивается — кириллица видна и копируется.
  - **Excel**: листы «Сводка» и «Детали», итоги формулами, автофильтр, закреплённая шапка; печать A4 альбомная
    по ширине листа, шапка таблицы повторяется, в колонтитулах — название, дата и «Лист N из M».
  - Оба формата строятся из одних данных и без сторонних библиотек (Excel не нужен).
- **Колонки настраиваются** (Вид → Колонки). По умолчанию: имя файла, толщина, габариты, количество,
  развертка, миниатюра. Можно добавить обозначение, наименование, материал, наличие развертки, итого на изделия,
  статус выгрузки, путь и любые пользовательские iProperties. Порядок меняется перетаскиванием заголовков.
- **Панель свойств** выбранной детали: крупная развертка, миниатюра и таблица свойств в стиле Details в Ansys —
  группы «Деталь», «Материал», «Развертка», «Резка», «Линии гиба», «Выгрузка», «Свойства iProperties»,
  в каждой строки «параметр | значение | единица» с сеткой. Главные результаты (масса, длина реза) — полужирным,
  проблемы — оранжевым или красным. Группы сворачиваются щелчком по заголовку (запоминается);
  значения можно выделить и скопировать. Та же таблица — в окне просмотра развертки.
- **Отметка** галочками — что выгружать: при добавлении в список детали не отмечены; отметка ставится галочкой,
  пробелом или кнопками группы «Отметка».
- **Выгрузка DXF**: «Выгрузить отмеченные» — отмеченные детали списка;
  «Выгрузить всё» — все листовые детали изделия. «Изделий: N» умножает количество.
  Статус по каждой детали в списке, CSV-отчёт для Excel.
- **Способ записи DXF**: по умолчанию — транслятор DXF Inventor с ini-файлом
  `Config/dxf_export_config.ini` (DXF 2004, только наружный и внутренние контуры и линии гиба,
  каждый в своём слое `IV_OUTER_PROFILE`, `IV_INTERIOR_PROFILES`, `IV_BEND`, `IV_BEND_DOWN`).
  Свой ini можно указать в «Параметрах выгрузки». Запасной способ — DataIO со строкой параметров.
- Шаблон имени файла: `{Name}-t{Thickness:0.0}мм-{Qty}шт`, доступны `{PartNumber}`, `{Description}`,
  `{Material}`, `{Length}`, `{Width}`, `{Assembly}` и любые iProperties. Пробелы в имени заменяются на `-`.
  Раскладка по папкам толщины (`3.0мм`, `1.5мм`) и по шаблону подпапок.
- **Линии гиба** (группа «Линии гиба» на ленте окна) — три уровня настроек: общие для всех деталей,
  свои для детали («Для выделенных») и свои для отдельных линий («По линиям»). Линия без своих параметров
  берёт параметры детали, деталь без своих — общие. В окне «По линиям» линии пронумерованы на развертке,
  выделенные подсвечены; можно выделить несколько линий и задать им параметры разом. Линия узнаётся по слою
  и координатам: если деталь изменили и линия сдвинулась, её настройка перестаёт действовать.
  Способы (выпадающий список): оставить как есть; удалить полностью; удалить, оставив прорези заданной
  длины у краёв; прерывистая линия — прорези одинаковые, перемычки одинаковые, симметрично по длине;
  задаётся либо длина прорези и перемычки (количество подбирается, подгонка пропорционально / по прорези /
  по перемычке), либо длина прорези и количество (перемычки рассчитываются); у краёв прорезь или перемычка;
  прямоугольные вырезы заданной ширины вместо прорезей-отрезков (по всей длине или прерывисто, с той же
  раскладкой), в DXF — замкнутая полилиния на слое линии гиба; вырезы со скруглениями — паз
  «дуга — отрезок — дуга — отрезок» той же ширины и раскладки, радиус скругления — половина ширины, длина паза —
  вместе со скруглениями (участок короче ширины — круг); в DXF — замкнутая полилиния с выпуклостями, в R12 —
  два отрезка и две дуги.
  Диалог показывает расчёт по реальным линиям гиба детали, превью развертки — результат обработки.
  Обрабатываются отрезки на слоях `IV_BEND` / `IV_BEND_DOWN` в готовом DXF; остальное в файле не меняется.

**Настройки InvAuto** (на ленте Inventor и кнопка «Настройки приложения» в окне «Листовые детали»):

- **Кэш разверток** — папка, занятый объём, срок автоочистки, «Очистить кэш…».
- **Журнал** — папка, объём, срок хранения (проверяется при запуске Inventor), открыть сегодняшний файл,
  «Очистить журнал…».
- **Сброс настроек** — параметры выгрузки, линии гиба, вид окна, настройки приложения — по отдельности.
  Файл не удаляется, а переносится в `%APPDATA%\InvAuto\backup` с датой и временем.
- **О программе** — версии и все папки InvAuto.

Защиты при очистке: перед удалением показывается полный список файлов (имя, размер, дата) и то, что
удалено не будет, с причиной; кнопка удаления доступна только после флажка подтверждения, по умолчанию
в фокусе «Отмена». Папка проверяется: только `…\InvAuto\FlatCache` или `…\InvAuto\logs`, не корень диска
и не ссылка. Удаляются только `*.dxf` (кэш) или `*.log` (журнал) и только файлы из показанного списка;
ссылки и точки соединения не обходятся; файл, изменившийся после показа списка, пропускается; сегодняшний
журнал не удаляется; сама папка остаётся. Итог — по каждому файлу, полный список пишется в журнал.
Во время выгрузки или формирования разверток настройки недоступны.

## Структура

```
src/
  InvAuto.Core/          логика без Inventor: дерево состава и подсчёт количества, чтение DXF для превью,
                         шаблоны имён, настройки, отчёты (покрыта тестами)
  InvAuto.Inventor/      сам плагин
    AddInServer.cs       точка входа: находит функции и строит ленту
    Framework/           IFeature, FeatureContext, автопоиск функций, лента Inventor, иконки
    Framework/Ui/        общая тема окон (Theme.xaml), лента команд, контрол превью развертки
    InventorApi/         работа с Inventor: состав сборки, iProperties, превью, запись DXF
    Features/            функции — по папке на каждую
    Config/              dxf_export_config.ini — настройки транслятора DXF
    InvAuto.addin        регистрация плагина в Inventor
tests/InvAuto.Core.Tests/
```

## Сборка и установка

Нужны Windows, Visual Studio 2022 (17.8+, рабочая нагрузка «Разработка классических приложений .NET»)
и установленный Inventor.

1. Откройте `InvAuto.sln`.
2. Проект настроен на Inventor 2025 (.NET 8). Для другой версии поменяйте `InventorVersion`
   в `InvAuto.Inventor.csproj` или соберите командой `dotnet build -p:InventorVersion=2026`.
   Для версий до 2025 проект сам переключится на .NET Framework 4.8.
3. Соберите в конфигурации **Debug**: плагин сам скопируется в
   `%APPDATA%\Autodesk\ApplicationPlugins\InvAuto`. Закройте Inventor перед сборкой, иначе DLL будет занята.
4. Запустите Inventor — на вкладке **«Среды»** появится панель **InvAuto**.

Для отладки: Свойства проекта → Отладка → запуск внешней программы `Inventor.exe`.

Старый плагин можно оставить: у InvAuto свой GUID, они не конфликтуют.

## Как добавить новую функцию

1. Создайте папку `src/InvAuto.Inventor/Features/МояФункция/` и класс:

```csharp
public sealed class MyFeature : FeatureBase
{
    public override string Id => "MyFeature";              // уникальный, не менять после выпуска
    public override string DisplayName => "Моя функция";   // текст кнопки
    public override int Order => 50;                       // порядок кнопки на панели InvAuto
    // Окна делайте на WPF с общей темой: <ResourceDictionary Source="/InvAuto;component/Framework/Ui/Theme.xaml"/>
    // — там готовы стили ленты (RibbonGroup, RibbonButton), таблиц и панелей.
    public override RibbonTargets Targets => RibbonTargets.Assembly | RibbonTargets.Drawing;

    public override void Execute(FeatureContext context)
    {
        var doc = context.App.ActiveDocument;
        var settings = context.Settings.Load<MySettings>(Id);  // свои настройки, сохраняются в XML
        context.Log.Info("Работаю с " + doc.DisplayName);
        context.ShowInfo("Готово");
    }
}
```

2. Всё. Кнопка появится автоматически, исключения из `Execute` перехватываются, пишутся в лог
   и показываются пользователю.
3. Иконки (необязательно): положите `Resources/Icons/MyFeature.16.png` и `MyFeature.32.png`.
4. Логику, которую можно проверить без Inventor (расчёты, имена, форматы), выносите в `InvAuto.Core`
   и покрывайте тестами: `dotnet test`.

Функции можно поставлять и отдельными DLL: сборка со своими классами `FeatureBase`,
положенная в папку `Plugins` рядом с `InvAuto.dll`, подхватится при запуске Inventor.

## Как добавить новую модификацию линии гиба

Всё в `src/InvAuto.Core/Bends` (без Inventor, покрывается тестами):

1. Значение в `BendLineMode` и нужные параметры в `BendLineOptions` (+ строка в `Summary`).
2. Класс `IBendLineStrategy` в `BendLineStrategies.cs`: по длине линии возвращает участки, которые останутся
   (будут прорезаны), и понятное описание. Регистрация — в `BendLineStrategies.All`; в диалоге способ появится сам.
3. Если у способа есть параметры — панель с полями в `BendSettingsWindow.xaml` и их чтение в `Read`.
4. Тесты в `tests/InvAuto.Core.Tests/BendLineTests.cs`.

## Иконки

Стиль — как у Inventor 2025: тонкий контур 1 px, детали в изометрии с тремя оттенками граней,
спокойная серо-голубая гамма, цвет только как акцент. Мелкий размер рисуется отдельно, а не уменьшается.

- `assets/icons/имя.svg` — рисунок 32×32 (большие кнопки), `assets/icons/имя.16.svg` — рисунок 16×16
  (маленькие кнопки, дерево, PNG 16 px). Если варианта нет, берётся другой.
- `tools/icons/make_icons.py` — генератор этих SVG (геометрия и палитра в одном месте).
- `tools/icons/build-icons.mjs` — сборка: `Framework/Ui/Icons.xaml` (ключи `Icon.Имя` и `Icon.Имя.Small`),
  PNG для ленты Inventor в `Resources/Icons`, обзорный лист `assets/icons/preview.png`.

```
python tools/icons/make_icons.py
npm install playwright && npx playwright install chromium
node tools/icons/build-icons.mjs
```

Для кнопки на ленте Inventor добавьте соответствие «имя SVG → Id функции» в `RIBBON` в начале build-icons.mjs.
Сгенерированные файлы хранятся в репозитории, так что для сборки плагина Python и Node.js не нужны.

## Тесты

```
dotnet test tests/InvAuto.Core.Tests
```

Тестируется всё, что не требует запущенного Inventor (логика вынесена в `InvAuto.Core`):

- **Сквозной конвейер DXF** — реалистичный файл Inventor (DXF 2004, cp1251, слои, блоки, скругления, текст)
  проходит через каждый режим линий гиба; проверяются структура файла (пары кодов, секции, уникальные handle,
  `$HANDSEED`), неизменность контура и отверстий, геометрия линий гиба, сохранность кириллицы байт в байт.
- **Свойства раскладки линий гиба** на тысячах случайных сочетаний длин и параметров: участки внутри линии,
  не перекрываются, симметричны, прорези и перемычки одинаковые, правила каждого режима.
- **Имена и пути**: шаблоны, правила Windows (недопустимые символы, CON/NUL/COM1…), пробелы → «-»,
  папки по толщине, уникальные имена при совпадении.
- **Дерево состава**: количества через подсборки, сортировка как в спецификации, раскрытие/сворачивание.
- **Настройки**: каждое поле переживает сохранение, персональные настройки линий гиба, колонки без дублей.
- **Список и сортировка**: добавление без повторов, удаление, сохранение списка при обновлении состава,
  естественное сравнение строк (числа по величине, длинные номера, обозначения), пустые значения в конце.
- **Проверка**: каждое замечание и его отсутствие на чистой детали, важность «нет развертки» в зависимости от
  настройки выгрузки, незамкнутый контур с местами, мелкие отверстия по толщине и минимуму, отверстия у линии гиба
  и на ней, размер листа с поворотом, повтор обозначений (но не один и тот же файл), итоги, расстояние между
  отрезками, добавление колонки «Проверка» в сохранённые настройки.
- **Ведомость**: группировка и итоги (прочерк вместо нуля при отсутствии данных), порядок позиций, имя файла,
  чтение шрифта TrueType, структура PDF (A4 альбомная, листы, смещения xref, встроенный шрифт, ToUnicode),
  пакет Excel (корректный XML всех частей, листы, формулы, автофильтр, картинки, параметры печати).
- **Материалы и показатели**: стартовая библиотека, материал по умолчанию для толщины (один на толщину),
  ручное назначение и откат к толщине, проверка библиотеки, резервные копии, повреждённый файл не
  перезаписывается, экспорт/импорт CSV и XML (числа с запятой, кавычки), слияние без удаления;
  площадь, длина реза и врезки по контуру из отдельных отрезков и дуг, масса.
- **Измерения**: точные отрезки и дуги из DXF, в том числе из блоков с поворотом и зеркалом; привязки
  и их приоритет; расстояния, углы (стороны по месту щелчка, продолжения, параллельные); ход измерения.
- **Чтение DXF для превью**: дуги, полилинии с bulge, сплайны, эллипсы, вложенные и самоссылающиеся блоки.
- **Безопасная очистка**: отказ для чужих папок, корня диска и ссылок, ссылки внутри не обходятся,
  посторонние и изменившиеся файлы не удаляются, сама папка остаётся; сброс настроек с резервной копией.
- **Отчёт CSV, лог, кэш разверток.**

Работа с Inventor API (сканирование сборки, транслятор, окна) проверяется вручную в Inventor.

## Известные ограничения

- Детали с несколькими состояниями модели (Model States) одного файла считаются одной позицией.
- Персональные настройки линий гиба привязаны к полному пути файла детали: после переноса
  или переименования файла их нужно задать заново.
