# Изменения

## 1.0.0

Первый выпуск.

**Листовые детали** (вкладка «Среды» → InvAuto):
- список деталей, собираемый пользователем из дерева сборки; отметки для выгрузки; сортировка по колонкам; поиск;
  сохранённые списки (по желанию);
- выгрузка разверток в DXF (ini транслятора Inventor или DataIO), шаблоны имён файлов и папок, раскладка по толщине,
  количество на изделие, CSV-отчёт;
- просмотр развертки: масштаб, измерения расстояний и углов с привязками, номера линий гиба, места замечаний;
- поворот развертки по выбранной линии (повторный щелчок — разворот на 180°), отдельно для каждой детали.

**Линии гиба**: оставить, удалить, прорези у краёв, прерывистая линия, прямоугольные и скруглённые пазы —
общие настройки, для детали и для отдельной линии.
**Законцовки линий гиба** (окружность, квадрат 0°, 45°): выемки в наружном контуре, вычитание из детали
при пересечениях и в углах (Clipper2), отдельные вырезы внутри детали; показ красным.

**Маркировка** обозначением детали (по умолчанию выключена): автоматическое место на металле с отступами,
ручное место, поворот, текст вдоль линии; предупреждения проверки.

**Производство**: библиотека материалов (плотность, толщина, материал по умолчанию для толщины; импорт и экспорт),
масса, площадь, длина реза, врезки; ведомость для заявки на резку в Excel и PDF (A4, заголовок, нумерация листов).

**Проверка перед выгрузкой**: развертка, сохранение, обозначение, материал, малые отверстия, отверстия у линий гиба,
размер листа, повторяющиеся обозначения, маркировка; пропуск замечаний для детали до её изменения.

**Настройки InvAuto**: сроки хранения кэша и журнала, безопасная очистка, сброс отдельных групп настроек,
параметры проверки, сведения о программе.

Установка — `InvAuto-1.0.0-Inventor2025-setup.exe` (см. README).
